# AHUCM_passw
Example of creating a password for universities

Данный код показывает логику примитивного создания пароля и его последующий ввод в поле ввода. Пример используется на основе входа в систему университета Anhui University of Chinese Medicine. 

В оригинальном коде находится база данных со всеми аккаунтами и их информацией, но вы можете практиковаться на нём, добавив от себя словари или вложенные списки для имитации небольшой базы.
